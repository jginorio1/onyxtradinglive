Para desplegar:

     (o copia los archivos). Tu lib/i18n/pt.ts NO se sobreescribe.
  2) git add -A && git commit -m "Activar Portugués + selector idioma login"
  3) git push   (Vercel redespliega solo)

Si algún día extraes en una carpeta LIMPIA (sin tu pt.ts), copia tu
lib/i18n/pt.ts a mano antes de compilar, o Portugués saldrá en inglés.
